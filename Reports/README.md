# Word-отчёты EnergyMeter System

Оригиналы восьми DOCX (ПР1–ПР7 и Э1), оформленные с титульным листом по образцу, находятся в ZIP-архиве, переданном в чате.

Чтобы добавить их сюда, откройте эту папку на GitHub, нажмите **Add file → Upload files**, выберите все 8 `.docx` из папки `Reports` архива и сохраните коммит. В документах уже указан настоящий адрес https://github.com/Girfor/EnergyMeter-System.

Текстовые копии для просмотра в браузере: [Reports_text](../Reports_text). Подтверждение CI: [9/9 тестов](../CI_REPORT.md).
