# Мини-ТЗ с ориентацией на ГОСТ 19.201-78

**Назначение:** приём накопительных показаний электросчётчиков и чтение их через HTTP API.

**Функции:** `POST /api/readings`, `GET /api/readings/{meterId}`, `GET /healthz`; защита запросов по `X-API-Key`; Swagger только в Development; cookie-действие кабинета с anti-forgery проверкой.

**Вход:** meterId латинские заглавные буквы/цифры/дефис (3–24), valueKwh [0; 1 000 000] кВт⋅ч, observedAtUtc не позже +5 минут и не раньше 5 лет от текущего UTC.

**Выход:** HTTP 201 / 400 / 401 / 409 / 503, JSON. При совпадении meterId и момента времени — 409.

**Надёжность:** потокобезопасная память для прототипа; для промышленной версии — постоянное хранилище с уникальным ограничением.

**Безопасность:** TLS, секреты вне кода, deny by default, CSRF для cookie-сеанса, Swagger только Development.

**Приёмка:** xUnit, интеграционные тесты, отдельная проверка Production, логи CI.

**Ограничение:** демонстрационный прототип, не промышленная АСКУЭ.
