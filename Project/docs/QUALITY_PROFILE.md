# Профиль качества EnergyMeter System

Экспертная иллюстративная оценка по восьми характеристикам ISO/IEC 25010:2011. Оценки **не являются инструментальным измерением**, проведённым на развёрнутой системе. Данные соответствуют диаграмме в оригинальном отчёте ПР5.

| Характеристика | До исправлений | После исправлений |
| --- | ---: | ---: |
| Функциональная пригодность | 4 | 4 |
| Надёжность | 2 | 3 |
| Эффективность производительности | 3 | 3 |
| Удобство использования | 3 | 3 |
| Защищённость | 1 | 3 |
| Совместимость | 3 | 3 |
| Сопровождаемость | 3 | 4 |
| Переносимость | 4 | 4 |

Шкала 1–5. Ключевой прирост при исправлении небезопасной конфигурации Swagger и добавлении защиты CSRF: защищённость 1 → 3. Сохраняющиеся ограничения: in-memory хранение, нет боевого управления аутентификацией, не проведено нагрузочное тестирование.

Указанные 8 характеристик соответствуют редакции стандарта 2011 года, требуемой заданием; в ISO/IEC 25010:2023 модель включает девять характеристик.
