# Текстовые версии отчётов

Эти 8 файлов содержат текст из Word-отчётов ПР1–ПР7 и Э1, подготовленных по МДК 03.02 для EnergyMeter System. В тексте присутствуют маркеры страниц, а исходные графические материалы и оформление титульников представлены в **оригинальных DOCX**.

Текстовые версии нельзя выдавать за Word-отчёты по ГОСТ. Оригинальные DOCX с действующими ссылками на GitHub доступны в полном архиве, переданном пользователю в чате.

Для помещения оригинальных файлов в этот репозиторий откройте **Add file → Upload files**, выберите все восемь из папки `Reports` и выполните коммит.
